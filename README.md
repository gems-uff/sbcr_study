
# Instructions:

1. Create a new conda environment
```sh
$ conda create -n sbcr_study python=3.8

$ conda activate sbcr_study

$ python -m pip install -r requirements.txt
```

2. Run the following script to prepare the datasets: `./prepare_dataset.sh`
    - Dataset1: SBES 2022 Dataset (https://doi.org/10.6084/m9.figshare.26831818) Paper: https://doi.org/10.1145/3555228.3555229
    - Dataset2: FSE 2022 Dataset (https://zenodo.org/records/6366908) Paper: https://doi.org/10.1145/3540250.354916


8. Run the following script to extract datasets stats: `./collect_dataset_stats.sh`


3. Run the following script to train the MergeGen approach using each dataset: `./train_all_models.sh`
    * This action might take a long time, depending on your setup


4. Run the following script to execute the MergeGen approach using each dataset: `./test_all_models.sh`


5. Run the following script to extract the similarities for the candidates generated by MergeGen approach using each dataset: `./extract_all_mergeGen_similarities.sh`


6. Run the following script to execute the sbcr approach tunning: `./tunning_sbcr.sh`


7. Run the following script to execute the sbcr approach evaluation: `./evaluate_sbcr.sh`
